ASP.NET Core Web API & SignalR Ayarları

Arkadaşınızın C# (.NET 10) Web API sunucusuna ve SignalR Hub uç noktasına bağlanmak için aşağıdaki URL'leri yapılandırabilirsiniz.

JWT Bearer & C# Model Eşleşmesi: 
// C# Controller Model
POST /api/exams/evaluate-batch
Headers: Authorization: Bearer {token}
Body: MultipartFormData (files[], examId, templateId)
SignalR Hub Event: "ReceiveProgress(processedCount, totalCount)"
